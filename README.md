# 🖥️ Verified Platform Backend

Ce projet est le backend de la plateforme **Verified**, développé avec **Laravel** pour gérer l'authentification et la vérification de documents.

---

## 🚀 Prérequis

Avant de commencer, assure-toi d'avoir installé :

- [PHP](https://www.php.net/downloads.php) (Version recommandée : `>= 10`)
- [Composer](https://getcomposer.org/) (Gestionnaire de dépendances PHP)
- [MySQL](https://dev.mysql.com/downloads/mysql/) (Base de données)
- [Laravel](https://laravel.com/docs) (Framework PHP)
- Un serveur web comme [Apache](https://httpd.apache.org/) ou [Laravel Sail](https://laravel.com/docs/10.x/sail)

---
